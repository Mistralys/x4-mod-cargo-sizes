# WP-003: Frontend Type Definitions and API Client

## Overview

Add TypeScript type definitions matching the new and updated backend DTOs, create the class-range API client method, and implement the `useClassRange` hook for state management and debounced API calls.

## Plan Reference

**Plan Steps:** 17–22 (Phases 3 + 4)

## Description

This work package bridges the backend and frontend by defining the TypeScript interfaces that mirror the backend DTOs, adding the API client method for the class-range endpoint, and creating the React hook that manages class-range state with debounced API calls.

## Requirements

### Step 17: Add TypeScript Types for Class-Range
- File: `gui/frontend/src/types/physics.d.ts`
- Add interfaces:
  - `ClassRangeRequest` — mirrors the backend DTO fields
  - `RangeMetric` — `{ min: number, max: number, median: number, unit: string, label: string }`
  - `ShipMetricSummary` — `{ shipId: string, shipName: string, size: string, massRatio: number, topSpeed: { original: number, adjusted: number } | null, acceleration: { original: number, adjusted: number } | null, dragChangePercent: number }`
  - `ClassRangeResponse` — `{ shipCount: number, metrics: Record<string, RangeMetric>, worstCase: ShipMetricSummary, bestCase: ShipMetricSummary }`

### Step 18: Update `ShipDetails` Interface
- File: `gui/frontend/src/types/ships.d.ts`
- Add `engineCount: number`
- Add `cargoType: string`

### Step 19: Update `EnginePerformance` Interface
- File: `gui/frontend/src/types/physics.d.ts`
- Add `originalTopSpeed: number | null`
- Add `adjustedTopSpeed: number | null`
- Add `engineCount: number`

### Step 20: Update `PhysicsResponse` Interface
- File: `gui/frontend/src/types/physics.d.ts`
- Add absolute metric fields matching the updated backend response (topSpeed, acceleration — original and adjusted, nullable).

### Step 21: Add Class-Range API Method
- File: `gui/frontend/src/services/api.ts`
- Add `classRangeApi.calculate(request: ClassRangeRequest): Promise<ClassRangeResponse>`
- Calls `POST /calculate/class-range`.

### Step 22: Create `useClassRange` Hook
- File: `gui/frontend/src/hooks/useClassRange.ts`
- State: `result: ClassRangeResponse | null`, `loading: boolean`, `error: string | null`
- `calculate(request: ClassRangeRequest): void` — debounced at 500ms (longer than single-ship 300ms for heavier computation)
- `reset(): void` — clear state
- Return type: `UseClassRangeResult`

## Technical Constraints

- **TypeScript strict mode** — must pass `strict: true` compilation.
- **No new npm dependencies**.
- 500ms debounce for class-range hook (vs 300ms for single-ship).
- Follow existing Hook and API client patterns in the codebase.
