# WP-007: Update Existing Single-Ship Results with Absolute Metrics

## Overview

Update the existing single-ship results components (`PhysicsOverview`, `ComparisonView`, `EnginePerformanceDisplay`) to display the new absolute metric fields (top speed, acceleration) returned by the updated backend, using `AbsoluteMetricCard` components alongside existing percentage-based data.

## Plan Reference

**Plan Steps:** 32–33 (Phase 8)

## Description

With WP-001 providing real data and absolute metrics in the backend response, and WP-004 providing the `AbsoluteMetricCard` component, the existing single-ship result views need to leverage these new data points. This WP adds absolute metric display to the existing result panels, complementing (not replacing) the percentage-based views.

## Requirements

### Step 32: Update `PhysicsOverview` and `ComparisonView`
- Modify `gui/frontend/src/components/ResultsPanel/PhysicsOverview.tsx`:
  - Display top speed (original vs adjusted) in m/s using `AbsoluteMetricCard` when an engine is selected.
  - Display acceleration (original vs adjusted) in m/s² using `AbsoluteMetricCard` when an engine is selected.
  - Position absolute metric cards alongside existing percentage comparisons.
- Modify `gui/frontend/src/components/ResultsPanel/ComparisonView.tsx`:
  - Include absolute metric fields from the updated `PhysicsResponse` in the comparison display.

### Step 33: Update `EnginePerformanceDisplay`
- Modify `gui/frontend/src/components/ResultsPanel/EnginePerformanceDisplay.tsx`:
  - Show top speed (original vs adjusted) in m/s alongside existing TWR display.
  - Show for all flight modes (normal, boost, travel) when data is available.
  - Use the new `EnginePerformance` fields (`originalTopSpeed`, `adjustedTopSpeed`).

## Technical Constraints

- **TypeScript strict mode** — modifications must compile under `strict: true`.
- **No new npm dependencies**.
- **No breaking changes** — existing display remains; new metrics are additive.
- Use `AbsoluteMetricCard` component from WP-004 for consistency.
- Context phrases from WP-005 can be used with `AbsoluteMetricCard`'s `contextPhrase` prop.

## Files Modified

- `gui/frontend/src/components/ResultsPanel/PhysicsOverview.tsx`
- `gui/frontend/src/components/ResultsPanel/ComparisonView.tsx`
- `gui/frontend/src/components/ResultsPanel/EnginePerformanceDisplay.tsx`

## Files Created

None.

## Dependencies

- **WP-004** — `AbsoluteMetricCard` component must exist.

## Acceptance Criteria

1. When an engine is selected, `PhysicsOverview` displays top speed (m/s) and acceleration (m/s²) as `AbsoluteMetricCard` components.
2. When no engine is selected, absolute metric cards are hidden — no "null" or "N/A" clutter.
3. `ComparisonView` includes absolute metric data from `PhysicsResponse`.
4. `EnginePerformanceDisplay` shows top speed for normal/boost/travel modes alongside existing TWR.
5. Existing percentage-based display remains intact — absolute metrics are additive.
6. All modified files compile under TypeScript strict mode.
