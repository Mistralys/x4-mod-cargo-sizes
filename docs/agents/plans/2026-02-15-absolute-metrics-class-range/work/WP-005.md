# WP-005: Context Phrases Utility

## Overview

Create a utility module with functions that return brief contextual phrases for absolute metric values, giving users intuitive context for physics numbers (e.g., "typical freighter speed", "sluggish response").

## Plan Reference

**Plan Steps:** 31 (Phase 7)

## Description

Absolute values like "412 m/s" or "8.3 m/s²" are meaningful to experienced X4 modders but benefit from brief context phrases that place them in the game's performance spectrum. This utility provides functions that take a metric value and optional ship size, returning a short descriptive phrase.

## Requirements

### Step 31: Create Context Phrase Functions
- File: `gui/frontend/src/utils/metricContext.ts`
- Functions:

#### `getSpeedContext(speedMs: number, shipSize: string): string`
- < 100 m/s: "very slow — heavy hauler"
- 100–200 m/s: "typical freighter speed"
- 200–350 m/s: "corvette range"
- 350–500 m/s: "fast fighter territory"
- \> 500 m/s: "extremely fast — possibly unbalanced"

#### `getAccelerationContext(accelMs2: number, shipSize: string): string`
- < 5 m/s²: "sluggish response"
- 5–20 m/s²: "standard acceleration"
- 20–50 m/s²: "nimble"
- \> 50 m/s²: "fighter-like responsiveness"

#### `getMassRatioContext(ratio: number): string`
- < 1.5: "minimal mass increase"
- 1.5–3.0: "noticeable but manageable"
- 3.0–10.0: "significant — will affect handling"
- \> 10.0: "extreme — may feel unresponsive"

## Technical Constraints

- **TypeScript strict mode** — must compile under `strict: true`.
- **No new npm dependencies**.
- Context phrases are approximate and tunable — label them as "approximate context" in tooltips.
- Thresholds are easily adjustable constants, not magic numbers buried in logic.
